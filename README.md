# مطاعم أسماك وادي النيل — Streamlit

نسخة تحويل أولية من مشروع Flask المرفوع إلى Streamlit، مع واجهة عربية RTL، تصنيفات المنيو والبحث والسلة وتسجيل الطلبات والفروع ولوحة إدارة.

## التشغيل محليًا
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح https://share.streamlit.io/ واربط GitHub.
3. اختر المستودع والفرع وملف `app.py` ثم Deploy.
4. من إعدادات التطبيق أضف Secrets:
```toml
ADMIN_USERNAME = "غيّر_اسم_المستخدم"
ADMIN_PASSWORD = "ضع_كلمة_مرور_قوية"
```

## ملاحظات مهمة قبل النشر الفعلي
- قاعدة البيانات المضمنة من المشروع الأصلي والأسعار الموروثة ليست مؤكدة كمنيو رسمي حديث؛ راجعها قبل عرض الأسعار للعملاء.
- SQLite داخل استضافة التطبيقات ليست ضمانًا للتخزين الدائم؛ البيانات الجديدة قد لا تبقى بعد إعادة نشر التطبيق أو إعادة تهيئة البيئة. استخدم قاعدة بيانات دائمة/خارجية إذا كان استقبال الطلبات الفعلية مطلوبًا.
- غيّر كلمة مرور الإدارة الافتراضية قبل النشر العام.
- نسخة التحويل تحتاج اختبارًا عمليًا للصور، وسير الطلبات، والصلاحيات، والبيانات قبل اعتمادها للإنتاج.
