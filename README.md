# مطاعم أسماك وادي النيل — موقع ويب مخصص

واجهة عربية RTL مبنية بـ HTML/CSS/JavaScript، وخلفية Python Flask، وقاعدة بيانات SQLite. تم الاحتفاظ بقاعدة بيانات الأصناف الحالية والصور المرفقة والشعار.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. افتح CMD داخل مجلد المشروع.
3. نفّذ:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py app.py
```

4. افتح `http://127.0.0.1:5000` في المتصفح.

## دخول لوحة الإدارة

الرابط: `/admin/login`

الافتراضي المحلي: اسم المستخدم `admin` وكلمة المرور `WadiNile@2026`.
**غيّر كلمة المرور قبل نشر الموقع** عبر متغير البيئة `ADMIN_PASSWORD`، وغيّر `SECRET_KEY` أيضًا.

## النشر على Render

المشروع يحتوي على `render.yaml` و`Procfile`. ارفع المجلد إلى مستودع GitHub، ثم أنشئ Web Service على Render من المستودع. اضبط `ADMIN_PASSWORD` كمتغير سري.

### تنبيه قاعدة البيانات

SQLite داخل حاوية استضافة مؤقتة قد تفقد التغييرات عند إعادة النشر أو إعادة إنشاء الحاوية. لحفظ الطلبات والأصناف بشكل دائم على استضافة سحابية، استخدم قرصًا دائمًا يدعمه مزود الاستضافة أو قاعدة بيانات PostgreSQL. الملف الحالي يحتفظ بقاعدة البيانات المحلية المرفقة، لكنه لا يضمن دوام بيانات الطلبات في استضافة مؤقتة.

## الوظائف الحالية

- الصفحة الرئيسية، قائمة الطعام والبحث والتصنيفات.
- بطاقات متساوية ومنسقة، أسعار وإضافة للسلة.
- سلة الطلبات وتسجيل بيانات العميل والفرع والعنوان والملاحظات.
- صفحات الفروع، عن المطعم، والتواصل.
- لوحة إدارة للدخول، إضافة الأصناف، إخفاء/إظهار الأصناف، ومراجعة الطلبات وحذفها.
- محاولة مطابقة الصور ذات الأسماء الواضحة مع أسماء الأصناف، مع إبقاء الصور غير المطابقة دون ادعاء أنها صورة الصنف الصحيح.

## ملاحظة

هذه نسخة أولية قابلة للتشغيل والاختبار. لم يتم إجراء اختبار مستخدم شامل أو ربط بوابة دفع أو خدمة توصيل أو واتساب رسمي. إرسال الطلب يسجله في قاعدة البيانات، ولا يعني أن المطعم استلمه خارجيًا أو أكّد التوصيل.
